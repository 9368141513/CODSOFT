# 🌐 Web Development Projects (CODSOFT Level 1)

This repository contains three beginner-friendly **web development projects** created as part of the **CODSOFT Internship – Level 1 Tasks**.  
Each project is built using **HTML**, **CSS**, and **JavaScript** and demonstrates core front-end concepts like layout, styling, and interactivity.

---

## 🧩 Projects Included

### 1. 🧑‍💼 Portfolio
A personal portfolio website built with HTML and CSS.  
It showcases your bio, skills, and project highlights.

**Features**
- Header with name/logo and navigation
- About section with image and bio
- Skills section listing expertise
- Projects showcase
- Contact and footer sections

---

### 2. 🚀 Landing Page
A responsive landing page for a product or service, focusing on layout and design.

**Features**
- Hero section with CTA
- Features and Pricing sections
- Smooth scrolling navigation
- Modern responsive design

---

### 3. 🧮 Calculator
A basic calculator built with HTML, CSS, and JavaScript.

**Features**
- Buttons for all basic arithmetic operations  
- Clear, percent, and sign change functionality  
- Keyboard input support  
- Responsive layout
