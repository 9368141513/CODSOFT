# Portfolio
Simple responsive portfolio site.

## Structure
- `index.html`
- `css/style.css`
- `js/script.js`
- `images/` (add profile images)

## How to run
Open `index.html` in your browser.

## To publish on GitHub
Create a repository (e.g. `portfolio`) and push files. Enable GitHub Pages from the repository settings (branch `main` / `gh-pages`).
